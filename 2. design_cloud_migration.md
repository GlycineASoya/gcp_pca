# Design. Cloud Migration Strategies

## Lift and Shift

Moving as it is from on-prem to cloud

- "+" - the cloud infrastructure is similar to the on-prem
- "+" - easy to reproduce
- "+" - less time consuming

- "-" - the cloud infrastructure might lack of best practicies and optimizations

## Improve and move

Moving on-prem to cloud step by step using hybrid approach

- "+" - balanced approach

- "-" - time consuming

## Remove and replace

Decommission on-prem infastructure and replacing it with pure cloud

- "+" - cloud native approach

- "-" - time consuming
