# Design. Success Measurements

## Business

1. Total Cost of Ownership (TCO)
2. Return on Investment (ROI)
3. Development agility (time from code to production)
4. Key Performance Indicators (KPI)

## Technical

1. Service availability
2. Service response times
3. Error rates
4. Mean time to recovery (MTTR)

## Relevant to users (Worth implementing)

1. Service availability
2. Service response time
3. Service error rate

## Irrelevant to users (Good for engineers)

1. Server availability
2. Server or DB latency
3. Server errors
